采集

真正难的是「什么时候不该砍」

一个只会砍树的 bot 在生存里是负资产——它会在你被三只僵尸追着跑的时候
突然转身去砍旁边那棵树，然后你死了它还站着。

所以这一层的主体不是「怎么砍」，而是门控。

门控：三值化

判据全部三值化：

  • Neg —— 明确不许
  • Zero —— 不确定（也不许，但不算「危险」）
  • Pos —— 才动手

合成规则是「任一 Neg 压过全部，任一 Zero 降级为不确定」。

砍树（gather_target = wood）

判据不许砍不确定 → 也不砍默认值
威胁有敌人威胁状态未知（刚死过 / 数据过期）—
血量< 65%65%~80% 临界带gather_min_hp
饱食度≤ 7读不到gather_min_food
爆炸源苦力怕 ≤10 格——
敌距兜底≤ 16 格威胁判据可能滞后，距离是独立通道—
昼夜夜里不知道时间（按夜里处理）gather_night
有没有树视野内没有 / 超过 20 格—gather_max_walk
配额这一趟砍够了—gather_quota
卡死单棵树砍 25 秒还没断—gather_max_chop_ms

挖矿多出来的三条

砍树站着不动就行，挖矿是在改变自己脚下的地形。
多出来的三条判据，每一条背后都是一次具体的死法：

判据为什么后果
脚下要有支撑（no_floor）挖矿时会不自觉往前挪，前方是刚挖开的坑掉进自己挖的坑，坑底可能是岩浆
目标不能是岩浆（lava）矿石 tag 和危险 tag 是两套判据，blk_front 只报一个类别必须先看危险，再看收益
前方被墙挡就换目标（blocked）地上能绕，矿道里绕不了对着墙走十秒和「卡死」是同一个观感

一格土坎 vs 两格墙

还有一个只能靠硬件区分的东西。

在「1 格处有固体」这个判断里，一格高的土坎和两格高的墙一模一样，
但前者该跳、后者该绕。

所以快通道多一条：

execute at @s rotated ~0 0 positioned ^ ^ ^1 \
  if block ~ ~ ~ #trit_bridge:solid unless block ~ ~1 ~ #trit_bridge:solid \
  run scoreboard players set stp trit_bridge 1

少了这一条，AI 会把每一个土坎都当死路——表现是「明明能走的地方它站住不动」，
而且只在有地形起伏的地方发作。

三条让它「看起来像人」的机制

1. 非对称的进入/退出

退出是当拍的（慢一点就来不及），
进入要连续 2.5 秒明确安全——中间闪一下不确定就重头计时。

这个「攒窗口」是防抽搐的第一道锁。

2. 被打断要吃惩罚冷却

威胁退出后锁 8 秒不许开工。

没有这一条，怪物稍微走远一点它就回去砍、砍两下怪又回来——原地抽搐。
真人不会这么干，真人会「这地方不安全了，先走」。

3. 干活时插播扫视

每 1.6 秒停手 350ms，左右转头。

挖矿多出来的三条机制

挖矿除了门控，还有三条特有的：

机制说明
只挖露头的矿射线打到方块才挖，不追地下的
换目标要冷却挖不到就换一个，别在一个点上耗 25 秒
挖矿时不乱走挖矿要站在原地，所以脚下支撑是硬判据

视线闭环

挖矿要瞄准矿脉，瞄准要转视角，转视角要等感知回来——这是个环。

处理办法（behaviors.rs）：

  1. 转向目标方位
  2. 停手等感知（等多久是量出来的，见 感知）
  3. 看准星对着什么
  4. 是矿石 → 挥击；不是 → 继续转

慢通道下压 30° 视线要 2~3 次、约 3.6 秒；
快通道下只要 2 次、约 0.7 秒。这就是快通道的实际价值。

配一条命令试

# 模拟一整趟采集（不真的动）
cargo run --release -- sim --gather

# 模拟挖矿
cargo run --release -- sim --mine

第一次实机建议：gather_quota = 1、gather_target = wood。
先砍树再试挖矿——挖矿的判据多，出问题的面也大。
